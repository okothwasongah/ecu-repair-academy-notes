# ECU Repair Academy — Study Notes
### Full-depth per-module student notes · Jatelo Technologies · August 2026

These are the student-facing study notes for the ECU Repair Academy programme — one file per module. Each follows the same structure: learning objectives, expanded theory and lecture notes with concrete electrical values, tools, step-by-step procedures, failure-mode tables, bench labs, and an assessment block (5 MCQs + 2 practical scenarios with answer keys).

They pair with the separate **master plan** document, which covers the platform architecture, the interactive sandbox, the decision-tree engine, and the database schema.

## Ethics & legal boundary

The programme excludes and does not teach: immobiliser/anti-theft defeat for unauthorised vehicles, odometer manipulation, and emissions-defeat calibrations (EGR/DPF/SCR/AdBlue delete, lambda removal, DTC masking). Cloning and EEPROM pairing are taught strictly as owner/authorised-repairer recovery for a specific vehicle. Module 7 carries a mandatory signed legal/ethics acknowledgement before enrolment.
