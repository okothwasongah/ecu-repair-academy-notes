One team. Every layer of the stack.

From the network cable to the customer's M-Pesa prompt — Jatelo builds, secures, deploys and operates every layer itself. Nothing here is outsourced.

FULL-STACK DEVELOPMENT

End-to-end product engineering across server, browser and app.

  • Node.js / Express, Python (Django, Flask, FastAPI), TypeScript
  • REST and GraphQL API design, JWT / OAuth2 session auth, RBAC
  • Socket.IO and WebSocket real-time messaging and event delivery
  • React, Next.js, Vue, and vanilla JavaScript SPAs
  • Progressive web apps (PWA) with offline-first sync patterns
  • Server-side rendering, static generation, and microservice / monorepo architecture

MOBILE & DESKTOP

Shipping real installable software, not just web pages.

  • React Native and Flutter cross-platform mobile apps
  • Native Android (Kotlin) and iOS (Swift) capability
  • Electron and native desktop packaging alongside Debian .deb / AppImage builds
  • Windows portable executables, Android .apk builds
  • Offline-capable single-file HTML builds and offline-first data sync
  • ECDSA P-256 signed licence-key activation, device-limited installs

DEVOPS & INFRASTRUCTURE

Provisioning, shipping and keeping systems running.

  • Docker containerisation, Kubernetes orchestration awareness
  • CI/CD pipelines — GitHub Actions, GitLab CI, Jenkins
  • Railway, AWS, Google Cloud, Azure and DigitalOcean deployment targets
  • Nginx reverse proxies, load balancing, zero-downtime and blue-green deploys
  • Custom domain migration — CNAME / TXT verification, DNS cutover
  • Managed switches, VLANs and subnetting for office/lab networks
  • Observability — logging, Sentry error tracking, Prometheus / Grafana monitoring

DATA & CLOUD

Choosing the right store for the job, not one store for everything.

  • Firebase — Auth, Firestore, Storage
  • Supabase, PostgreSQL and MySQL for relational, structured data
  • MongoDB for document-oriented workloads
  • Redis and BullMQ for caching, queues and background jobs
  • SQLite for offline and embedded deployments
  • Vector search (pgvector / Pinecone-style) for AI retrieval workloads
  • Snapshotted records and audit trails so reprints always match what was issued

PAYMENTS ENGINEERING

Mobile money, card rails and bank settlement, all treated as first-class.

  • Mobile money — M-Pesa Daraja (STK push, B2C payouts, C2B callbacks), Airtel Money
  • Card payment routes — Visa and Mastercard acquiring via Stripe, Flutterwave, Paystack, DPO Group and PayPal
  • Card tokenization, 3D Secure and PCI-DSS-aware handling
  • Bank transfer reconciliation and settlement reporting
  • Callback-driven escrow — funds released only against confirmed settlement
  • Prepaid credit systems and per-task metered billing
  • Multi-currency, multi-country tax, VAT and settlement configuration

MEDIA & REAL-TIME SYSTEMS

Video, voice, live streams and instant messaging at production scale.

  • Cloudflare video storage, transcoding and streaming
  • RTMP live ingest and WebRTC peer connections
  • Programmatic video generation (Remotion-based rendering pipelines)
  • AI voice synthesis (ElevenLabs) and text-to-speech pipelines
  • Live chat, stream credential issuance, Socket.IO-driven notifications
  • OCR pipelines (Google Cloud Vision) for document and prescription reading

AI & APPLIED RESEARCH

Production AI features and autonomous-agent research work.

  • Claude API and OpenAI API integration, prompt engineering, streaming responses

  • Retrieval-augmented generation and vector-search-backed AI features

Built to hold real money and real personal data safely.
